# Keypads

Lutron Alisse keypad mockups that clients can edit, served at https://keypads.audio1975.com

- One page per project, e.g. `40-bedford.html`. The project's keypads are the `ORIGINAL` data near the top of its script.
- Clients tap a keypad to edit it. Edits save in their browser; **Send changes** makes a link (email or copy) that opens their version. **Download for Google Sheet (CSV)** matches the Alisse keypad Google Sheet's Keypads tab.
- `CNAME` holds the custom domain. DNS: a CNAME record `keypads` → `salesaudio1975.github.io` at GoDaddy.
- Pages are marked `noindex`; the home page doesn't list projects.
